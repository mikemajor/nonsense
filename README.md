# nonsense

Small, silly projects, one per folder. Each folder has its own README with the details.

| Folder | What it is | Language | Live |
|---|---|---|---|
| [`tottingham/`](tottingham/) | Reports whether it's St. Totteringham's Day: the day Arsenal become mathematically certain to finish above Tottenham in the Premier League. Can email you when it happens. | Perl | |
| [`inrainbowfy/`](inrainbowfy/) | Turns your text into the cover of Radiohead's *In Rainbows*, in the cover's typeface and colors, and saves it as a PNG. | PHP, SVG | [mmajor.com/ir](https://www.mmajor.com/ir/) |

## Adding a project

Put it in its own folder with a `README.md`, and add a row to the table above.
